# Спокійний собака на вулиці і вдома · навчальна платформа

Сторінка для учнів курсу Наталки Виноградської: відеоуроки, конспекти, розклад онлайн-занять із Zoom, Google Календарем і анкетами.

- `index.html` — уся платформа. Розклад (`MEETINGS`) і уроки (`LESSONS`) задаються в блоці «НАЛАШТУВАННЯ» у скрипті внизу сторінки.
- `pdf/` — конспекти уроків.

Публікується через GitHub Pages.
